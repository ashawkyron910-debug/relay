Relay
How to run it

Download Relay and start talking.

Servers, text channels, and direct messages for Linux and Windows. Install the app, open it, and sign in.

Linux

AppImage or Debian package

Download AppImage · 104 MB Download .deb · 72 MB

The AppImage runs without installing. The .deb adds a Relay entry to your app menu.

Windows

Setup wizard or zip

Download setup · 79 MB Download zip · 107 MB

Use the setup file for a normal install. The zip is a portable copy of the app.

Run the app

  1. Download the file for your system.
  2. Linux AppImage, in a terminal: 
    chmod +x Relay-0.1.0.AppImage
./Relay-0.1.0.AppImage
    Or install the package with sudo apt install ./relay-desktop_0.1.0_amd64.deb and open Relay from the menu.
  3. Windows: double-click Relay Setup 0.1.0.exe and follow the installer. From the zip, open the folder and start relay.exe.
  4. On the sign-in screen, leave the server as http://127.0.0.1:4000 if the server is on this computer. Create an account, then create a server and share its invite code.

Let other people join

  1. On the computer that hosts Relay, open this project and run:
npm run install:all
npm start
  1. The terminal prints a network address, such as http://192.168.1.113:4000.
  2. Everyone else types that address into the Server field before they register or log in.
  3. Share the invite code from the server menu so they can join the same rooms.
